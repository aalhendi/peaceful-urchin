# Peaceful Urchin

A loan and credit microservices task using .NET and PostgreSQL. The [task](task.md) defines the required behavior and deliverables.

## AI Use Disclosure

OpenAI GPT 6-Sol (Proprietary) and local Google Gemma-4-E4B (Apache 2.0) used as research and learning aids. No code generation was used. AI use was restricted to find and compare online sources such as https://learn.microsoft.com, and my personal Obsidian vault. Additionally, it helped translate concepts I know from Rust / Java into C# and .NET.

In that sense, I treat it as a **glorified search engine and concept translator**, with a human in the loop for decisions, verification and implementation.

The disclosure will be updated accordingly in the case any changes occur.
